# WBS 관리

## 개요

WBS(Work Breakdown Structure)는 프로젝트 목표 달성을 위해
전체 작업을 계층적으로 분해하고 일정과 담당 업무를 관리하는 체계이다.

## 목적

- 프로젝트 범위 명확화
- 작업 단위 정의
- 일정 추적
- 진척률 관리
- 담당자별 업무 현황 관리

## WBS 구성 요소

| 항목 | 설명 |
|---|---|
| Phase | 프로젝트 단계 |
| Task | 수행 작업 |
| 담당자 | 작업 책임자 |
| 시작일 | 작업 시작 일정 |
| 종료일 | 작업 완료 일정 |
| 상태 | 진행 상태 |
| 진척률 | 작업 진행률 |

## 관리 기준

- 주기적인 진척 현황 업데이트
- 일정 지연 항목 식별
- 선행/후행 작업 관계 관리
- 변경 사항 반영
