# 일정 관리

## 개요

프로젝트 일정 관리는 WBS 기반으로 작업 일정을 수립하고,
진행 현황을 추적하여 프로젝트 목표 일정 준수를 관리하는 활동이다.

## 목적

- 프로젝트 완료 일정 관리
- 작업 간 선후 관계 관리
- 일정 지연 요소 식별
- 진척 현황 공유

## 주요 관리 항목

| 항목 | 설명 |
|---|---|
| Baseline | 최초 승인 일정 |
| Actual | 실제 수행 일정 |
| Progress | 작업 진척률 |
| Milestone | 주요 완료 기준 |
| Dependency | 작업 간 선후 관계 |

## 관리 기준

- 주기적인 일정 현황 업데이트
- 지연 작업 식별 및 원인 분석
- 변경 사항 발생 시 일정 영향 검토
- 주요 마일스톤 관리

## 산출물

- 프로젝트 일정표
- WBS 일정 관리표
- 주간 진행 현황 보고서
- Milestone 관리표
