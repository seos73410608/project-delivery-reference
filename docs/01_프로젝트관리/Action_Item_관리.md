# Action Item 관리

## 개요

Action Item 관리는 프로젝트 수행 과정에서 발생하는 결정 사항,
요청 사항, 개선 사항 및 후속 조치 항목을 등록하고 완료까지 추적 관리하는 활동이다.

회의, 이슈, 리스크 관리 과정에서 도출된 실행 항목을 체계적으로 관리하여
프로젝트 진행 상황과 책임 소재를 명확하게 관리한다.

---

## 목적

- 프로젝트 주요 실행 사항 추적 관리
- 담당자 및 완료 일정 명확화
- 미완료 항목 관리
- 프로젝트 진행 현황 가시성 확보
- 의사결정 사항의 실행력 확보
