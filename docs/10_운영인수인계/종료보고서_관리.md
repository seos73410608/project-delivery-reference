# 종료보고서 관리

## 개요

종료보고서 관리는 프로젝트 수행 결과를 종합적으로 정리하고,
프로젝트 목표 달성 여부와 완료 기준을 확인하여 공식적인 종료 절차를 수행하는 활동이다.

프로젝트 수행 과정에서 생성된 산출물, 검수 결과, 운영 인수인계 현황 및
잔여 관리 항목을 정리하여 프로젝트 종료 승인을 지원한다.

---

## 목적

- 프로젝트 수행 결과 정리
- 목표 및 범위 완료 여부 확인
- 산출물 제출 현황 관리
- 운영 인수인계 완료 확인
- 프로젝트 종료 승인 지원
