# CI 관계 모델

## 개요

CI 관계 모델은 CMDB에서 관리되는 구성 항목(Configuration Item) 간의
연결 관계를 정의하는 체계이다.

IT 시스템은 하나의 구성 요소로 운영되지 않으며,
Server, OS, Middleware, Application, Database 등 다양한 구성 요소가
서로 연결되어 서비스가 제공된다.

CI 간 관계 정보를 관리함으로써 장애 분석, 변경 영향 분석 및
운영 관리를 효율적으로 수행할 수 있다.

---

## 목적

- 구성 요소 간 연결 관계 관리
- 변경 영향 범위 분석 지원
- 장애 발생 시 연관 시스템 파악
- 서비스 구성 구조 가시화
- 운영 인수인계 효율 향상
