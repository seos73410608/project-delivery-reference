# 서버 CI 관리

## 개요

서버 CI(Configuration Item) 관리는 프로젝트 및 운영 환경에서
사용되는 물리 서버와 가상 서버의 구성 정보를 관리하는 활동이다.

서버의 하드웨어 정보, 운영체제 정보, 네트워크 정보 및 설치 Software 정보를
체계적으로 관리하여 시스템 구성 현황 파악과 변경 영향 분석을 지원한다.

---

## 목적

- 서버 구성 정보 표준화
- 서버 현황 가시화
- 설치 및 구축 정보 관리
- 변경 발생 시 영향 분석 지원
- 운영 인수인계 자료 확보
