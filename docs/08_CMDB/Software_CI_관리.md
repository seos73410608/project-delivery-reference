# Software CI 관리

## 개요

Software CI(Configuration Item) 관리는 프로젝트 및 운영 환경에
설치되는 Software 구성 요소의 정보를 관리하는 활동이다.

Middleware, Application, Utility 및 시스템 운영 Software의
제품 정보, 버전, 설치 위치 및 구성 정보를 관리하여
시스템 구성 현황과 변경 이력을 추적할 수 있도록 한다.

---

## 목적

- Software 구성 정보 표준화
- 설치 현황 관리
- Version 정보 관리
- 변경 영향 분석 지원
- 운영 환경 구성 정보 확보

---
