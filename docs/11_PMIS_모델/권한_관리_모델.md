# 권한 관리 모델

## 개요

권한 관리 모델은 PMIS 사용자의 역할과 접근 권한을
체계적으로 관리하기 위한 데이터 모델이다.

사용자별 업무 범위와 역할에 따라
메뉴 접근, 데이터 조회 및 변경 권한을 제어하여
프로젝트 정보의 보안성과 관리 효율성을 확보한다.

---

## 목적

- 사용자 인증 체계 확보
- 역할 기반 권한 관리
- 프로젝트별 접근 제어
- 데이터 보안 강화
- 운영 관리 기준 표준화
