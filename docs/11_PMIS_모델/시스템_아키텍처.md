# 시스템 아키텍처

## 개요

PMIS(Project Management Information System)는
프로젝트 수행 과정에서 발생하는 관리 데이터를 통합하고,
일정, 이슈, 구성 정보 및 보고서를 체계적으로 관리하기 위한
웹 기반 프로젝트 관리 시스템이다.

본 시스템은 기존 문서 기반 PMO 업무를 시스템화하는 것을 목표로 하며,
Spring Boot 기반 Backend와 MariaDB 기반 Database 구조로 설계한다.

---
