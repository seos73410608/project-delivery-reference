# 이슈 관리 모델

## 개요

이슈 관리 모델은 프로젝트 수행 과정에서 발생하는
문제 사항, 위험 요소 및 조치 항목을 체계적으로 관리하기 위한
PMIS 핵심 데이터 모델이다.

Issue, Risk, Action Item을 통합 관리하여
프로젝트 영향도를 분석하고 조치 완료까지 추적하는 것을 목적으로 한다.

---

## 목적

- 프로젝트 이슈 통합 관리
- 위험 요소 사전 관리
- 조치 사항 추적
- 담당자 책임 관리
- 프로젝트 의사결정 지원
