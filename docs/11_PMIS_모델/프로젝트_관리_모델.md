# 프로젝트 관리 모델

## 개요

프로젝트 관리 모델은 PMIS에서 프로젝트 수행 정보를 관리하기 위한
기본 데이터 구조와 관리 기준을 정의한다.

프로젝트 기본 정보, 참여 조직, 일정, 상태 및 진행 현황을
통합 관리하여 프로젝트 전반의 현황 추적을 지원한다.

---

## 목적

- 프로젝트 기본 정보 표준화
- 프로젝트 진행 상태 관리
- 프로젝트별 업무 범위 관리
- 참여 조직 및 담당자 관리
- Dashboard 및 Report 데이터 제공
