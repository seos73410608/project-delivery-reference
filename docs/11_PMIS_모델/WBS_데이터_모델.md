# WBS 데이터 모델

## 개요

WBS(Work Breakdown Structure) 데이터 모델은
프로젝트 수행 업무를 계층 구조로 분해하고,
작업 일정, 담당자, 진행 상태 및 진척률을 관리하기 위한
PMIS 핵심 데이터 모델이다.

프로젝트 목표를 단계별 작업 단위로 관리하여
일정 추적과 프로젝트 진척 현황 분석을 지원한다.

---

## 목적

- 프로젝트 작업 구조 표준화
- 작업 단위별 일정 관리
- 담당자 책임 관리
- 진척률 추적
- Dashboard 및 Report 데이터 제공
