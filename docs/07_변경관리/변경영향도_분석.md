# 변경영향도 분석

## 개요

변경영향도 분석은 프로젝트 수행 과정에서 발생한 변경 요청이
프로젝트 일정, 범위, 기술 환경, 품질 및 운영에 미치는 영향을
사전에 분석하는 활동이다.

변경 반영 전 영향 범위를 파악하여 적절한 의사결정을 지원하고,
변경으로 인한 프로젝트 위험 요소를 최소화한다.

---

## 목적

- 변경 사항의 영향 범위 분석
- 일정 및 작업 영향 사전 검토
- 기술적 영향 확인
- 변경 승인 판단 근거 제공
- 변경으로 인한 위험 최소화
