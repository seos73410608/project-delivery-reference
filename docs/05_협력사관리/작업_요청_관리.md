# 작업 요청 관리

## 개요

작업 요청 관리는 프로젝트 수행 과정에서 필요한 구축 작업, 변경 작업,
점검 작업 등을 협력사 또는 담당 조직에 요청하고 진행 상황을 관리하는 활동이다.

요청된 작업의 범위, 일정, 담당자, 결과를 체계적으로 관리하여
프로젝트 일정 준수와 작업 품질 확보를 지원한다.

---

## 목적

- 작업 요청 사항 체계적 관리
- 작업 범위 및 책임 명확화
- 작업 일정 추적
- 요청 사항 누락 방지
- 작업 결과 검증 및 기록 관리
