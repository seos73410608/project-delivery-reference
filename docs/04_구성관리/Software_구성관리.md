# Software 구성관리

## 개요

Software 구성관리는 프로젝트 및 운영 환경에 설치되는 소프트웨어 구성 요소를
식별하고 버전, 설치 정보, 설정 정보를 관리하는 활동이다.

운영체제, 데이터베이스, 미들웨어, 업무 시스템 등 주요 Software 정보를 관리하여
시스템 구성 현황과 변경 이력을 추적한다.

---

## 목적

- 설치 Software 현황 관리
- Version 정보 관리
- 구성 변경 사항 추적
- 시스템 구성 정보 최신화
- 운영 이관 자료 확보
