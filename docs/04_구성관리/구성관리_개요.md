# 구성관리 개요

## 개요

구성관리는 프로젝트 및 운영 환경을 구성하는 시스템 구성 요소(Configuration Item, CI)를
식별하고 등록하여 변경 사항과 구성 정보를 체계적으로 관리하는 활동이다.

서버, 운영체제, 데이터베이스, 미들웨어, 네트워크 등 주요 구성 요소의 정보를 관리하여
시스템 구성 상태에 대한 가시성과 추적성을 확보한다.

---

## 목적

- 시스템 구성 정보의 체계적 관리
- 구성 요소 간 관계 파악
- 변경 사항 추적 및 영향 분석
- 장애 발생 시 원인 분석 지원
- 운영 이관 및 유지보수 기반 확보

---

## 구성관리 대상(Configuration Item)

구성관리 대상은 프로젝트 및 운영 환경을 구성하는 관리 항목이다.

| 구분 | 관리 대상 |
|---|---|
| Server | 물리 서버, 가상 서버 |
| OS | 운영체제 및 버전 |
| Database | DBMS, Instance, Schema |
| Middleware | WAS, Web Server |
| Software | 설치 프로그램 및 버전 |
| Network | IP, Port, 연결 정보 |
| Application | 서비스 및 배포 버전 |
