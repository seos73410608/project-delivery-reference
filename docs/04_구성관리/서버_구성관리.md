# 서버 구성관리

## 개요

서버 구성관리는 프로젝트 및 운영 환경에서 사용되는 서버 자원의 구성 정보를
식별하고 관리하는 활동이다.

서버의 하드웨어 자원, 운영체제, 네트워크 정보 및 설치 Software 정보를 관리하여
시스템 구성 현황을 파악하고 변경 사항을 추적한다.

---

## 목적

- 서버 구성 정보 체계적 관리
- 구축 대상 서버 현황 관리
- 서버 변경 사항 추적
- 장애 발생 시 원인 분석 지원
- 운영 이관을 위한 구성 정보 확보

---

## 서버 구성관리 프로세스

```text
서버 대상 식별
        ↓
서버 정보 등록
        ↓
