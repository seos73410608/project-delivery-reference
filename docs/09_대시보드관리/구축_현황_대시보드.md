# 구축 현황 대시보드

## 개요

구축 현황 대시보드는 프로젝트 구축 단계에서 수행되는
서버, 운영체제, 데이터베이스, Middleware 및 Software 설치 작업의
진행 상태를 통합 관리하기 위한 Dashboard 체계이다.

구축 대상, 작업 일정, 수행 상태 및 완료 여부를 시각화하여
프로젝트 진행 현황을 파악하고 일정 지연 요소를 관리한다.

---

## 목적

- 구축 작업 진행 현황 가시화
- 설치 대상별 완료 상태 관리
- 일정 지연 사전 식별
- 벤더 작업 현황 관리
- 구축 완료 증적 확보
