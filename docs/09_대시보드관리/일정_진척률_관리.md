# 일정 진척률 관리

## 개요

일정 진척률 관리는 프로젝트 WBS 기반으로
계획 일정과 실제 수행 현황을 비교하여 프로젝트 진행 상태를
정량적으로 관리하는 활동이다.

Dashboard에서는 일정 데이터를 기반으로 프로젝트 전체 진행률,
단계별 진행 상태 및 지연 항목을 시각화하여 관리한다.

---

## 목적

- 프로젝트 일정 진행 현황 파악
- 계획 대비 실적 비교
- 일정 지연 조기 식별
- 주요 Milestone 관리
- 프로젝트 완료 가능성 판단 지원
